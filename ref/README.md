# Референсы

Сюда кладутся образцы, по которым делается дашборд: скриншоты, макеты,
ссылки списком в `links.md`.

Картинки из этой папки не попадают в git — это чужие работы, и в публичном
репозитории им не место. Разбор референса и принятые из него решения живут
в тексте навыка, сами файлы остаются локальными.

Если какой-то файл нужно закоммитить намеренно — добавь его через
`git add -f ref/имя-файла`.
