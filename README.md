# Son of Orchestrator

**Скажи словами, что нужно построить — получи готовый проект.**

Навык для AI-агентов (Claude Code, Cursor, Codex). Берёт идею, задаёт 5–8
вопросов на человеческом языке, дальше сам пишет техзадание, разбивает на задачи
и собирает проект. Читать спецификации и код не нужно.

Младший в семье Culture of Orchestrating. Старший — совет критиков, который
спорит и ловит ошибки. Этот — строит.

## Установка

```
npx skills add vladsamatov2006-art/son-of-orchestrator
```

Или вручную:

```
mkdir -p ~/.claude/skills/son-of-orchestrator
cp skills/son-of-orchestrator/SKILL.md ~/.claude/skills/son-of-orchestrator/
```

Зависимостей нет. Если в окружении есть навык `code-review` — финальное ревью
пойдёт через него, иначе агент сделает его сам.

## Как пользоваться

Открой агента в папке будущего проекта:

```
/son-of-orchestrator Нужен сайт-визитка для студии маникюра, с записью и галереей
```

Или просто опиши задачу словами — агент поймёт сам:

> Собери мне под ключ лендинг для клиента, не задавай лишних вопросов

Дальше отвечаешь на несколько вопросов в начале. Остальное происходит без тебя.

## Как это работает

Пять фаз. Код пишется только в четвёртой — до этого агент разбирается,
что именно строить. Результат каждой фазы ложится файлом в `.orchestrator/`
внутри проекта: расшифровка интервью, техзадание, список задач. Читать их не
обязательно — они нужны агентам, у которых на сборке чистая память.

1. **Вопросы** — 5–8 штук на человеческом языке. Блокирующее (хостинг, оплата,
   доступы, где брать контент) спрашивается первым, а не на финише.
2. **Техзадание** — из твоих ответов. Новых вопросов нет, неизвестное помечается
   как `PLACEHOLDER`.
3. **Задачи** — разбивка + один экран простым языком. Одобрять не нужно:
   «запускаю через 60 секунд, если не скажешь стоп».
4. **Сборка** — одна задача = один агент с чистой памятью, один коммит на задачу
   (точки отката). После каждой — строка отчёта без жаргона.
5. **Финиш** — что построено, чем запустить, что не построено, что осталось
   открытым.

## Стек по умолчанию

Технические решения принимает агент, из ответов на понятные вопросы:

- контентный сайт, который клиент правит сам → WordPress
- админка или своя логика работы с данными → Filament
- лендинг без правок клиентом → статика

## Чего навык не делает

- не пишет код до техзадания;
- не отвечает за тебя и не выдумывает содержимое;
- не просит проверять задачи или код;
- не запускает две задачи в одной памяти агента;
- не оставляет оплату, ключи и хостинг на финиш.

## Когда НЕ использовать

Хочешь проектировать вместе шаг за шагом — вызывай навыки пайплайна по
отдельности. Задача на правку одного файла — просто попроси её сделать.
Нужен разбор и критика готового — это работа старшего, а не этого навыка.
